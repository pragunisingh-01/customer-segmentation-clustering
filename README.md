# Customer Segmentation Using Machine Learning

## Overview
This project uses exploratory data analysis (EDA) and unsupervised machine learning to segment customers based on demographics, income, spending habits, and purchasing behavior.

## Technologies Used
- Python, Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn, PCA
- K-Means and Agglomerative Clustering

## Workflow
- Data cleaning and exploratory data analysis
- Feature engineering and preprocessing
- Dimensionality reduction using PCA
- Cluster selection using the Elbow Method and Silhouette Score
- Customer segmentation and cluster analysis

## Results
Identified four customer clusters and analyzed differences in customer spending and purchasing behavior.

## How to Run
1. Install the required Python libraries.
2. Place `smartcart_customers.csv` in the expected directory.
3. Open `Smart.cart_Customer.ipynb` in Jupyter Notebook.
4. Run the cells sequentially.
